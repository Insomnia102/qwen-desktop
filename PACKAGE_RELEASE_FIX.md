## Обязательная подготовка

```bash
pnpm exec node scripts/prepare-release.mjs
pnpm install
pnpm exec node scripts/ci-check.mjs
```

Точная версия pnpm в package.json намеренно не угадана. Первая команда берёт вашу версию из окружения pnpm и записывает packageManager. Если окружение не передано, выполните `pnpm --version`, затем `node scripts/prepare-release.mjs --pnpm-version X.Y.Z` с полученной версией.

После установки добавьте в коммит package.json, pnpm-lock.yaml, обновлённый .gitignore, исправленный скрипт и остальные файлы релизного обновления. При зелёных проверках создавайте тег v1.0.0 согласно docs/RELEASING.md. До этого тег не отправляйте.

Проверены шесть тестов релизной подготовки и отдельный запуск скрипта с данным manifest, включая ./main path, версию 1.0.0, сохранение существующих полей и gitignore. Полная установка зависимостей по вашему lockfile здесь не выполнялась: сам lockfile ещё не предоставлен.
