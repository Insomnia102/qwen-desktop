## Зачем нужен Qwen Desktop?

Qwen Desktop даёт Qwen Code графическое рабочее пространство: откройте проект, опишите задачу, наблюдайте за работой агента и управляйте его доступом к инструментам.

Ведите отдельные диалоги для разных проектов, возвращайтесь к сохранённым чатам и настраивайте модели, MCP-серверы и skills в одном интерфейсе. Проект создан для тех, кому удобнее работать с агентом через настольное приложение.

Это независимый community-проект, а не официальное приложение Qwen.

## Что потребуется

- **Node.js 22 или новее вместе с npm** для первоначальной подготовки CLI. **Рекомендуется Node.js 26.x.** Скачать можно на [nodejs.org](https://nodejs.org/en/download).
- Интернет для установки CLI и обращения к провайдеру модели.
- API-ключ поддерживаемого провайдера или существующая совместимая конфигурация Qwen. Доступ к модели настраивается отдельно.

**Глобально устанавливать Qwen CLI заранее не нужно.** Приложение найдёт совместимую установку или установит свою копию. Если Node.js или npm отсутствуют, первый экран объяснит, что установить. Требования добавленных вами MCP-серверов и skills учитываются отдельно.

## Возможности

- **Проекты и сохранённые чаты.** Отдельные диалоги для каждой рабочей папки, история между запусками, переименование и удаление чатов. Рабочие области можно закрывать и открывать снова с сохранением переписки.
- **Читаемые ответы и ход работы.** Markdown, блоки кода, сворачиваемый журнал действий и рассуждения модели, если она их передаёт.
- **Управление разрешениями.** Режимы Plan, Ask Permissions, Auto-Edit, Auto и YOLO, подтверждение одной операции или операций в текущем диалоге.
- **Профили моделей.** Подключение OpenAI-совместимых, Anthropic-совместимых и Gemini API, проверка соединения и переключение моделей.
- **MCP-серверы.** Подключения через stdio, Streamable HTTP и SSE, просмотр доступных инструментов, их включение и отключение.
- **Пакеты skills.** Создание, импорт и редактирование навыков вместе с инструкциями, скриптами, правилами, справочными материалами и другими ресурсами прямо в приложении.
- **Системные промпты и slash-команды.** Настройка инструкций агента, вызов доступных команд и skills из чата.
- **Настройки через интерфейс.** Изменение поддерживаемых параметров Qwen и управление встроенными инструментами.
- **Три языка интерфейса и две темы.** Русский, английский и упрощённый китайский; светлое и тёмное оформление.

## Установка

Скачайте установщик в разделе [Releases](https://github.com/Tsukuyomi102/qwen-desktop/releases):

| Платформа | Архитектура | Формат загрузки |
| --- | --- | --- |
| Windows | x64 | `.exe` |
| macOS Intel | x64 | `.dmg` или `.zip` |
| macOS Apple Silicon | arm64 | `.dmg` или `.zip` |
| Linux | x64 | `.AppImage` или `.tar.gz` |

1. Установите приложение. На macOS перенесите его в Applications. На Linux разрешите запуск AppImage или распакуйте архив.
2. Откройте Qwen Desktop и завершите подготовку CLI. При необходимости установите Node.js с npm, перезапустите приложение и повторите проверку.
3. Выберите язык интерфейса и настройте подключение модели.
4. Проверьте соединение, откройте папку проекта и отправьте первую задачу.

Текущие установщики Windows не подписаны; сборки macOS используют ad-hoc подпись без notarization. При первом запуске ОС может запросить подтверждение.

Переписка сохраняется локально. Запросы к модели отправляются выбранному вами провайдеру. Разрешения управляют действиями агента; рабочая папка не является системной песочницей. YOLO автоматически подтверждает включённые инструменты.

## Планы

- [ ] **Агенты:** добавить интерфейс создания, редактирования и настройки агентов.
- [ ] **Workflows:** создавать, редактировать и повторно использовать рабочие сценарии внутри приложения.
- [ ] **Улучшенный редактор skills:** доработать редактирование кода, навигацию по ресурсам и проверки пакетов с несколькими файлами.

Это планы развития без обещания конкретных сроков. Предложения и сообщения об ошибках можно оставить в [Issues](https://github.com/Tsukuyomi102/qwen-desktop/issues).

## Запуск из исходников

Для разработки установите Node.js 26.x и указанную в проекте версию pnpm, затем выполните:

```bash
pnpm install
pnpm dev
```

Проверки проекта запускаются командой `node scripts/ci-check.mjs`.
